# ZestyZone-Django
# 🛍️ ZestyZone with User-Friendly Features

A dynamic and user-friendly e-commerce web application designed to provide a seamless shopping experience. This platform features robust user authentication, email verification, and an integrated Razorpay payment gateway. With secure transactions and easy product management, users can enjoy a smooth and efficient shopping experience.

---

## 🌟 Key Features

### 🔐 **User Authentication**
- **Signup with Email Verification**: New users must verify their accounts via email before logging in.
- **Secure Login**: Implements robust security to protect user data.

### 🛒 **Product Management**
- **Add to Cart**: Users can select products and add them to their cart.
- **Remove Products**: Mistaken selections can be easily removed.

### 💳 **Payment Integration**
- **Razorpay Payment Gateway**: Secure and reliable payment processing.
- **Transaction Status**: After payment, users are redirected to their profile page to view order details and transaction status.

### 👤 **Profile Management**
- View payment status, order details, and manage personal information in the user profile.

### 📱 **Responsive Frontend**
- Built with modern web technologies like HTML, CSS, JavaScript, and Bootstrap for a visually appealing and mobile-friendly interface.

---

## 🛠️ **Tech Stack**

- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Backend**: Python (Django Framework)
- **Database**: MySQL
- **Payment Gateway**: Razorpay
- **Version Control**: Git
